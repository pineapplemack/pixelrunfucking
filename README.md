# 像素水管工 · 教程 10 关 + 正片 9 关

一个类似马里奥的像素风横版动作网页游戏。

- **教程 1~10**：手把手教你走、跳、打、开箱、过坑，随时按 **T** 跳过
- **正片第 1~9 关**：难度逐关上升，所有机制混在一起，越往后怪越多越硬
- **地底第 1~5 关**：第 9 关末尾钻进绿色管道进入地下，主题换成岩洞，登场地底武器与新怪

带手持武器与冷却、怪物血条、存档点、墓碑回收、箱子、刷怪笼、弹簧、移动平台，关卡可以导出/导入 JSON。

**双击 `index.html` 就能玩**，不需要服务器、不需要安装任何东西（Chrome / Edge / Firefox 均可）。

## 操作

| 按键 | 作用 |
| --- | --- |
| ← → | 移动 |
| 空格 / ↑ | 跳（按住更高；**空中再按一次 = 二段跳**） |
| Shift | 加速跑 |
| ↓ | 蹲（大个子会降低受击盒）/ 空中 ↓+J 下砸 |
| **J** | 使用手上拿的武器（每种武器有自己的冷却） |
| **1~5 / Q** | 切换手上的武器（最多带 5 把） |
| **Tab** | 打开/关闭背包（看全部武器与技能，打开时暂停） |
| **Z / X / C** | 使用背包里第 1/2/3 个技能 |
| **T** | 跳过教程（只在教程关有效） |
| **L** | 冲刺：撞碎砖块、撞飞敌人，消耗 1 格能量 |
| **E** | 在技能祭坛前解锁技能 / 拾取武器 |
| P | 暂停 / 继续 |
| R | 回到本关最近的存档点 |
| M | 静音 |

## 玩法

- **血条**：260 点上限，受伤后 2.4 秒开始自动回血（每秒约 12 点）；血条空了就倒下。
- **死亡不掉进度**：倒下会回到本关最近的**存档点**（血条满、分数与金币保留），技能会掉在**墓碑**里。
- **墓碑**：死亡点立一块墓碑，跑回去按 E 就能取回全部武器等级；再次死亡会把墓碑挪到新的死亡点。
- **存档点**：每关自动布置 2 个（约 45% 与 80% 处），是一面会发光的旗子，走过即记录。
- **武器 / 背包**：快捷栏最多装 **5 把**（按 1~5 切换），再多捡到的会进**背包**。
  按 **Tab** 打开背包：`←→` 换栏、`↑↓` 选、`Enter` 装备/卸下，打开时游戏暂停。
- **死亡掉武器**：倒下后**背包里**的武器有概率丢失，概率从第一次的 40% 每死一次衰减到最低 5%。
  丢掉的会立成墓碑，跑回去按 E 能全部取回；快捷栏里的 5 把不会丢。
  出生自带铁拳套，其余靠**武器祭坛**（靠近按 E）、武器箱、墓碑拾取。

  | 武器 | 冷却 | 伤害 | 特点 |
  | --- | --- | --- | --- |
  | 铁拳套 | 0.34s | 14 | 出生自带 |
  | 星辉剑 | 0.44s | 26 | 出手快、范围长 |
  | 裂岩锤 | 1.15s | 46 | 砸碎砖块、震飞敌人 |
  | 火花杖 | 0.40s | 18 | 直线火弹，同屏 3 发 |
  | 散弹筒 | 1.00s | 12×3 | 三发扇形，近身很痛 |
  | 回旋镖 | 0.95s | 20 | 飞出再飞回，来回都打 |
  | 光束枪 | 1.35s | 32 | 穿透整条直线 |
| 熔岩钻头 | 0.70s | 30 | 地底武器，穿透一排敌人 + 破砖 |
| 霜冻法杖 | 0.55s | 14 | 命中减速 1.8 秒 |
| 榴弹炮 | 1.10s | 34 | 抛物线榴弹，落地炸开一片 |
| 雷链杖 | 1.00s | 22 | 瞬间电击最近的 3 只怪 |
- **能量**：每吃 10 枚金币 +1 格（上限 3 格），冲刺消耗 1 格。
- **金币**：+10 分；每 100 枚回复 30 点血。
- **形态**：小个子 → 吃蘑菇变超级（更高、蹲下可闪避）→ 吃火花变火焰 → 吃星星短暂无敌。
- **敌人**：
  - 圆栗：走来走去，可踩死。
  - 甲仔：踩一下变壳，踢出去连撞。
  - 扑扑：飞行，只能躲或远程打。
  - 探头花：管道里定时伸出，不能踩。
  - **吐弹花**：站桩，朝玩家吐弹幕。
  - **冲锋牛**：看到玩家会猛冲一段，撞墙后眩晕。
  - **刺球**：全身是刺，不能踩、冲刺也撞不动。
  - **蝙蝠**：追着玩家飞，速度快，只能打不能踩。
  - **炸弹兵**：边走边扔抛物线炸弹，落地或撞墙就炸。
  - **幽灵**：无视地形直线飘过来，慢但甩不掉（打得到它）。
  - **地鼠**：平时缩在土里，你靠近就跳出来撞人。
  - **炮台**：站桩，成对发射瞄准你的弹丸。
- **箱子**：路上有五种箱子，踩上去 / 近战 / 冲刺撞都能打开。
  - 武器箱：随机一项技能 +1 级
  - 金币箱：一次吃 6 枚金币
  - 陷阱箱：毒气爆炸，范围内扣血
  - 炸弹箱：大范围爆炸，顺手炸碎砖墙
  - 未知箱：问号箱，好坏随机（含少量回血）
- **弹簧**：踩上去直接弹到高处。
- **移动平台**：会横向来回移动，站上去会被带着走。
- **刷怪笼**：靠近后会不断吐怪（最多同时 3 只），打掉它就停止刷新。
- **难度**：每关敌人伤害 +9%（封顶 2.2 倍），后面几关会同时出现刷怪笼、刺球、冲锋牛。
- **技能**：路上开宝箱、打死怪物都有机会掉「技能球」，走过去自动捡。**最多带 3 个**，同种技能可叠层数。

  | 技能 | 键 | 效果 |
  | --- | --- | --- |
  | 治疗药水 | Z | 立刻回 80 血 |
  | 过载核心 | X | 8 秒内武器无冷却 |
  | 净化炸弹 | C | 干掉屏幕上全部敌人 |
  | 传送卷轴 | V | 直接跳到下一关 |

- **背包**：按 Tab 打开，5 个武器槽 + 3 个技能槽一屏看完，打开时游戏暂停。
- **怪物血条**：每只怪头顶都有血条。圆栗 34 血（剑 2 刀 / 锤 1 下 / 拳套 3 下），冲锋牛 86、刺球 110，越往后越硬。
- **管道出口**：正片第 9 关终点是一条绿色管道，**跳到管道顶上**会提示「按 E 进入管道」，按 E（或 ↓ / S）钻进管道进入地底篇。
- **过关**：跑到旗子处，奖励 2000 + 关卡序号 × 300 分。第 10 关通关后结算总分。

## 文件结构

所有文件平铺在同一个目录（这样直接丢到 GitHub Pages 就能跑）：

```
index.html   页面骨架（顶栏 + 舞台 + 双画布 + 触屏控件）
style.css    布局与顶栏样式
core.js      常量、调色板、瓦片类型、渲染尺寸
input.js     键盘 / 触屏输入
audio.js     WebAudio 合成音效
sprites.js   像素美术：角色/敌人/道具/瓦片/背景
weapons.js   武器表、技能表、图标绘制
physics.js   瓦片碰撞与移动
levels.js    关卡构建器 + 24 关
gen.js       随机关卡生成器（当前未启用）
entities.js  主角、敌人、道具、弹丸、粒子
game.js      主循环、镜头、HUD、背包、存档点、渲染
dev.js       开发者控制台 + 跳关面板
```

`tools/` 里是测试页，发布时不用传。

## 关卡 JSON

设置菜单里可以：

- **导出本关 JSON** —— 把当前关卡的瓦片、实体、出生点、旗子位置存成 `.json` 文件。
- **导入关卡 JSON** —— 选一个 json 文件，立刻作为新关卡游玩。

格式（`v:1`）：

```json
{ "v":1, "name":"我的关卡", "w":160, "h":22,
  "spawn":[2,18], "goal":[150,12],
  "rows":["0000...", "..."],
  "ents":[{"kind":"box","box":"weapon","x":320,"y":272}] }
```

`rows` 每行一个字符代表一个瓦片（0 空 / 1 地面 / 2 砖 / 3 金币砖 / 4 道具砖 / 5 石块 / 6 管道 / 7 已用砖）。

## 测试期跳关（之后会删）

右上角橙色的 **▾ 跳关** 按钮，点开就是全部 24 关的分组列表，点一下直接进关。也支持 `index.html#jump` 打开就弹出。

## 开发者控制台

按 **`**（数字 1 左边那个键）或 **F2**，或点顶栏的 `>_` 打开。可以直接输入作弊码：

| 指令 | 作用 |
| --- | --- |
| `lvl 5` | 跳到第 5 关 |
| `god` | 无敌开关 |
| `hp 250` | 改血量上限并回满 |
| `heal` / `coins 99` / `score 9999` | 回血 / 金币 / 分数 |
| `weapon all` | 一键拿齐全部 10 把武器 |
| `weapon list` / `weapon clear` | 列出武器属性 / 只剩铁拳套 |
| `weapon laser` | 拿指定武器 |
| `spawn bat` | 在面前刷一只怪 |
| `killall` | 清空当前敌人 |
| `noclip` | 穿墙开关 |
| `seed 1234` / `restart` | 改种子 / 重开 |
| `help` | 指令列表 |

`index.html#dev` 打开时会自动弹出控制台。

## 调试参数

- `index.html#lvl=2` —— 直接从第 3 关开始（0 起算）。
- `index.html#lvl=1&tx=30` —— 进关后把角色瞬移到第 30 格。
- `index.html#seed=1234` —— 固定随机种子（生成器用）。

## 实现说明

- 逻辑分辨率 640×352（40×22 格，每格 16 世界像素），每格绘制为 32 个「美术像素」，最终按窗口等比放大到 1280×704 再 CSS 拉伸，所以像素块清晰且角色足够大。
- 世界画在 `#game` 画布上（`image-rendering: pixelated`）；文字与 HUD 画在覆盖层 `#ui` 画布上，用系统字体、按设备像素比渲染，所以中文清晰不糊。
- 零外部依赖、零网络请求，所有美术与音效都在运行时生成。
